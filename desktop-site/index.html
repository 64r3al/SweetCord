A MORE FOCUSED DESKTOP

The essentials, without the extra noise.

SweetCord adds a lightweight layer of control around Discord's official web app. The goal is not magic performance numbers—it's giving you meaningful choices about visual work and interface clutter.

GOOD TO KNOW

Questions, answered.

The details matter—especially when a desktop app sits between you and a service you already use.

Is SweetCord a replacement for Discord?

No. SweetCord Desktop wraps Discord's official web app in a desktop window and applies optional interface and resource filters. The separate SweetCord web app is a distinct React/Supabase project and is not a Discord voice client.

Will it use less RAM than Discord?

It is designed to reduce selected visual-resource and interface work, but the Discord web client and Chromium still run. There is no hard RAM cap, and results depend on your PC and activity. Compare both apps in the same conditions before drawing conclusions.

Can I use voice chat?

The Electron wrapper allows microphone-only capture on HTTPS Discord origins. Camera and display capture are denied by its permission policy, and video and screen sharing are intentionally not supported in this mode.

Why are images missing in Extreme Lite?

Extreme Lite blocks image requests in the main Discord window and filters recognized visual media. Avatars, server icons, custom emoji, stickers, attachments, and embeds may therefore be absent. Choose Balanced or configure Custom settings if you prefer to keep more visuals.

Is SweetCord affiliated with Discord?

No. SweetCord is an independent, unofficial community project and is not affiliated with, endorsed by, or supported by Discord. Using a third-party wrapper may carry account or Terms of Service risks.

Is the Windows installer a stable release?

No. Published installers are preview builds. Review the release page and version notes, and do not assume that a prebuilt download contains every change on the main branch.
